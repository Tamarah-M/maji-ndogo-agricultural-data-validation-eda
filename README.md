# Maji Ndogo Agricultural Data Validation and Exploratory Data Analysis
## Project Overview

## This project focuses on data validation and exploratory data analysis (EDA) of the Maji Ndogo agricultural dataset. The analysis was performed using Python, SQL, Pandas, Matplotlib, and Seaborn to clean the data, explore patterns, and generate meaningful insights.

## Tools Used
- Python
- SQL
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
## Project Workflow
- Loaded the data from a SQL database.
- Validated and cleaned the dataset.
- Performed exploratory data analysis (EDA).
- Created visualizations to identify trends and relationships.
- Summarized key findings.
## Repository Files
- Maji_Ndogo_Agricultural_Data_Validation_EDA.ipynb – Main project notebook.
- requirements.txt – Required Python libraries.
